# TurnMate — 강사 근무·대직·급여 앱 리디자인

수영장 강사를 위한 대직·근무표·급여 관리 앱의 **고충실도(hi-fi) 리디자인 프로토타입**입니다.
원본 코드의 기능을 전부 세어 정리한 뒤, 그 위에서 화면을 다시 설계했습니다.

> **이 저장소는 디자인 레퍼런스입니다.** 실제 동작하는 프로토타입이지만 프로덕션 코드가 아닙니다.
> 대상 코드베이스의 기존 환경에서 다시 구현하는 것이 목적입니다. → [`docs/HANDOFF.md`](docs/HANDOFF.md)

## 리디자인 원칙

| 원칙 | 내용 |
|---|---|
| **입력 마찰 제거** | 강사가 직접 입력하는 항목을 최소화. 시간표·대상·난이도는 선택한 근무에서 자동으로 가져옴 |
| **터치 타깃 상향** | 원본의 10–11px 텍스트 200여 곳, 9px 배지, 36px 버튼 → 본문 14.5–16px / 주요 버튼 52px. 수영장에서 젖은 손으로 쓰는 앱 기준 |
| **색은 의미만** | 중립 잉크 + 정규(파랑) · 대직(주황) · 긴급(빨강) · 완료(초록). 그라데이션·이모지·8색 배지 제거 |

## 화면 구성

**강사 (탭 4개)**
- **홈** — 다음 근무 → 센터 도착 알림 → 긴급 대직 → 내 대직 → 월 급여
- **대직** — 모집 공고 지원(즉시 확정) / 내 요청 관리
- **일정** — 월간 캘린더 · 주간 타임라인(08–22시)
- **내 정보** — 프로필·자격증·급여 명세·설정·데모 계정 전환
- **온보딩** — 4단계 프로필 등록
- **대직 요청** — 3단계 전체 화면 (근무 선택 → 사유·메모 → 요약)

**관리자 (탭 5개)**
- **관제** — 긴급 미구인 카드 + 지표 + 오늘 출퇴근
- **승인** — 긴급/모집 중/확정 3분류, 직권 배정(후보 비교)
- **근무표** — 주간 그리드 · 월간 · 강사 상세 · 대직 확인서
- **급여** — 강사별 정산 · 조정 · 확정 잠금
- **설정** — 지급 단가 · 주간 기준 · 도착 인증 반경

## 주요 로직

### 급여
```
강습 1교시 = 경력단가        // 1년차 26,000 / 2년차 27,000 / 3년차 이상 28,000
안전 1시간 = 요일별 단가      // 평일 17,000 / 토·일 18,000
세전 = 정규강습 + 정규안전 + 대직강습 + 대직안전 + 관리자조정
원천징수 = round(세전 × 0.033)
실수령 = 세전 − 원천징수
```
대직 근무(`sub_assigned`)는 정규와 **분리 집계**해 강사가 구분해 볼 수 있게 했습니다.

### GPS 출근 반경 알림
- `watchPosition` + haversine 거리 → 반경 200m 진입 시 도착 시트 + 시스템 알림
- **진입 1회만 발화**, 나갈 때 `radius × 1.3` 이상 벗어나야 재무장 (경계 흔들림 방지)
- 권한은 토글 클릭 안에서만 요청. 차단·미지원·타임아웃을 각각 구분 안내하고 **수동 출근은 항상 가능**

> ⚠️ 웹은 탭이 열려 있을 때만 감지됩니다. 출근 시각 알림이 제품의 핵심이라면 네이티브 지오펜싱이 필요합니다. 상세는 [`docs/HANDOFF.md`](docs/HANDOFF.md).

## 아직 설계되지 않은 것

**정규시간표 자동 채움** — 이번 릴리스의 실제 목표이지만 프로토타입에는 반영되어 있지 않습니다.
현재 온보딩 3단계는 강사가 시간표를 직접 입력하는 구조입니다.

합의된 방향: 강사는 **이름·전화번호·근무 지점(드롭다운 1개)** 만 등록하고, 시간표는 원본 엑셀에서 시스템이 미리 채운 뒤 강사는 **`[맞아요]` 1탭으로 확인**만 합니다. 강사 화면에 시간표 편집 UI는 만들지 않습니다.
결정 사항·필요 화면·리스크는 [`docs/HANDOFF.md`](docs/HANDOFF.md)의 "미설계" 섹션 참고.
